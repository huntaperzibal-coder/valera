# Фокси — детский голосовой персонаж

Сайт: https://www.hunta.su (располагается на Мастерхосте).
Репозиторий назван `valera` по имени проекта, но **персонажа зовут Фокси**.

## Развёртывание
На Мастерхосте выполняется `~/valera-sync.sh`. Скрипт синхронизирует только `public/` с каталогом сайта.

## Админка
Отдельная панель для взрослого: **`https://www.hunta.su/admin/`** (каталог `public/admin/` попадает на сервер вместе с остальным `public/`).

- Вход — тот же родительский пароль, что и для включения ИИ на сайте.
- Не секретные параметры (модель, лимиты, голос SpeechKit, веб-поиск) хранятся в `~/valera-private/admin-settings.json` (создаётся из админки, не коммитится).
- Резервные копии: скачивание ZIP и выгрузка в Selectel через restic (бинарник и реквизиты только на сервере в `valera-private/`).
- **Развёртывание на боевой сервер** — только после проверки и отдельного разрешения; обновление кода: `~/valera-sync.sh`.

## Подключение ИИ
Реализован PHP API `public/api/chat.php` с родительским входом, ограничением запросов и коротким контекстом текущего диалога в браузере.

Пока серверный конфиг отсутствует, ИИ не активен. Для подключения требуется:
1. Платёжный аккаунт Yandex Cloud и сервисный аккаунт с минимальными правами `ai.languageModels.user`.
2. API-ключ с областью `yc.ai.foundationModels.execute` (для совместимого API; проверять актуальные требования).
3. Файл `/home/u551741/valera-private/config.php` с правами 600, создаваемый **на сервере**, не добавлять в GitHub:

```php
<?php
return [
    'api_key' => 'СЕКРЕТНЫЙ_КЛЮЧ',
    'folder_id' => 'ID_КАТАЛОГА',
    'model' => 'qwen3.6-35b-a3b',
    'parent_password_hash' => 'ХЕШ_РОДИТЕЛЬСКОГО_ПАРОЛЯ',
];
```

Хеш пароля можно получить командой `php -r 'echo password_hash("ВВЕДИТЕ_ДЛИННЫЙ_ПАРОЛЬ", PASSWORD_DEFAULT), PHP_EOL;'`, но не вставляйте реальный пароль в историю shell. Лучше вводить пароль без отображения и генерировать хеш из переменной окружения.

## Важно
Приложение ещё **не прошло тестирование с ребёнком** и пока не готово к его самостоятельному использованию. Текущий браузерный Web Speech API может пересылать аудиоданные стороннему провайдеру распознавания. Хранение детских разговоров на сервере не предусмотрено. Не включать сбор аналитики/логирование запросов и подключить необходимые ограничения обработки данных до детского использования.
